# Контур · ТН ВЭД

Локально вычисляемый веб-подбор ТН ВЭД. Статический сайт для GitHub Pages: стандартные HTML/CSS/ES modules и отдельный Web Worker. Без платных API, внешних шрифтов, аналитики и серверной обработки описаний.

Возможности: название и характеристики товара, фильтр по источнику, код/префикс, доли групп и полных кодов, дерево, признаки и противоречия, ссылки на исходные строки, кодовый скрининг нормативных перечней, экспорт JSON/TXT и до 30 сохранённых проверок в текущем браузере.

## Данные и границы применения

Срез ФНС 27.04.2026: 13 295 записей с периодами, включая переход 01.07.2026. Для выбранной даты применяется отбор по периодам. Даты до 27.04.2026 в веб-версии отклоняются. Более поздняя дата не подтверждает актуальность среза.

CSV содержит ссылки classifikators.ru. Его дата редакции и полнота не подтверждены; это не официальный источник ЕЭК. Цифровые префиксы определяют дерево; метки парсера `lvl` и обратные ссылки не принимаются за глубину иерархии.

48 637 уникальных пар товар/код из восьми пользовательских Excel-каталогов и информационного письма используются как примеры, не как правовые решения. Публикуется подготовленный индекс с наименованиями, кодами, названиями файлов и номерами строк. Исходные Excel/PDF, абсолютные локальные пути и история настольного приложения не включены. Индекс сайта доступен публично.

Проценты — **доли текстового соответствия среди найденных вариантов, не откалиброванные вероятности верного кода**. Даже 100% не устанавливают правильность. Не найденная ветвь не получает долю. Подтверждённый код всегда `null`; окончательный выбор требует проверки [официальной номенклатуры ЕЭК](https://eec.eaeunion.org/comission/department/catr/ett/), ОПИ, примечаний и документации товара.

Веса описания/материала/назначения/конструкции/параметров: 0.60/0.16/0.12/0.06/0.06, нормированные по заполненным полям. Примеры: до +0.12 за точное название Excel, +0.04 за аналог Excel, +0.01 за PDF. Явные распознанные противоречия умножают оценку на 0.15. Отбор: совпадение имени объекта, покрытие описания от 0.34, итог от max(0.08, четверть лучшей оценки). Проценты делятся по префиксам 2/4/6/8/10 пропорционально квадрату наибольшей оценки в ветви. Повторы не усиливают вес.

Веб-модель `web-hierarchical-support-v1` сохраняет формулу настольной версии, но ищет аналоги среди всех совпадений индекса, без предварительного SQLite FTS-лимита. Поэтому не обещается полное тождество выдачи для всех запросов. Основные реальные запросы и ключевые инварианты проверяются тестами.

Только ограниченное распознавание материалов и приводов. Числовые диапазоны, отрицания, правовые исключения и все классификационные решения не реализованы как юридические правила. Кодовые совпадения с ПП № 2425 и санитарным перечнем не устанавливают применимость требований. Полные технические регламенты, пошлины, льготы, запреты, маркировка и мониторинг законодательства не реализованы.

## Запуск, проверки, публикация

Требуется Node.js 22+; сторонних npm-зависимостей нет.

```sh
node --test tests/*.test.mjs
node scripts/build.mjs
python -m http.server 8768 --directory docs
```

GitHub Pages публикует `/docs` из основной ветви репозитория. `.nojekyll` отключает обработку Jekyll. Сборка копирует только разрешённый список файлов, проверяет синтаксис модулей и SHA-256 индекса. Изменение исходников требует повторной сборки перед коммитом. Никаких токенов в клиенте или репозитории нет.

`scripts/export_index.py` обновляет сжатый индекс из соседнего исходного настольного проекта `tnved`, SQLite и нормативных указателей. Без этого локального проекта скрипт экспорта не работает, но опубликованный сайт и его тесты работают по готовому индексу. Экспорт не скачивает новые редакции законодательства.

`manifest.json` и отчёты содержат версию модели и хеш индекса. Проверка SHA-256 выявляет случайное повреждение при загрузке, не защищает от изменения сайта его владельцем. История хранится в localStorage по явной команде пользователя, не синхронизируется и может быть очищена браузером.

При наличии `document.modelContext` регистрируется необязательное действие `classify_product`, использующее тот же ввод и отрисовку. Поддерживаемого контекста WebMCP для живой проверки при первоначальной разработке не было; регистрация не заявляется как проверенная в браузере. Отсутствие API не влияет на обычный интерфейс.
